## In

### 入口

侧栏数字员工区 **「+」** → 打开建岗向导（草图 `12`）。禁静默、禁跳到敬请期待页。

### 硬锁：空侧栏（v1.1）

- 冷启动 / 无本地已存岗时，数字员工列表为 **空态**（「还没有数字员工」+ 引导点「+」），**禁止**默认写入产品经理/运营/研协三角色。
- 列表项**只**来自用户通过向导创建（或用户曾创建后持久化恢复）。
- 验收用例须覆盖：空列表 →「+」→ 创建成功 → 侧栏恰好 1 岗。

### 三步（可合并 UI，语义要对齐）

| 步           | 最小可验                                                                                                                                        |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 选模板     | ≥4 卡：产品经理 / 运营 / 研协 / 空白；**产品经理必有**（对齐 `13`：人设摘要、预装 Skills 标签可展示为只读预览）                                 |
| 2 名称与职责 | 名称必填；职责描述可预填模板文案可改；所属账户可写死 `find-core` 或下拉假数据                                                                   |
| 3 准备沙箱   | 点 **「创建并准备沙箱」** → 按钮「创建中…」disabled → 成功：侧栏出现新岗并选中 + toast/绿态；失败：红卡（可关），明示原因（如「本地存储失败」） |

选模板后右侧/表单应带出模板默认名与职责（产品经理示例对齐 `13` 人设口吻即可，不必开管理后台页）。

### 数据最小形

```ts
type RoleTemplateId = 'pm' | 'ops' | 'rd' | 'blank';

type RoleTemplate = {
  id: RoleTemplateId;
  name: string; // 产品经理数字员工
  blurb: string; // 竞品·周报·闸门
  defaultDuty: string;
  presetSkills?: string[]; // 展示用，如 validation-gate
};

type CreateAgentInput = {
  templateId: RoleTemplateId;
  name: string;
  duty: string;
  accountId?: string; // 可默认 find-core
};

type AgentListItem = {
  id: string;
  name: string;
  templateId: RoleTemplateId;
  status: 'online' | 'busy' | 'idle';
};
```

持久化：桌面本地 store / memory fixture 即可；刷新后侧栏仍在（至少同会话）。  
**Out**：真云沙箱 provisioning、管理后台「岗位模板」全页（`13` 仅作模板内容真源）、Channels 真连通。
